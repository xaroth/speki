{{end}}This is a speki server: a knowledge base for AI agents. Knowledge lives as markdown in GitHub repositories, and agents such as Claude search, read and update it over MCP. GitHub decides who sees and changes what.

Connect your agent

In claude.ai or the Claude desktop app: Customize, Connectors, Add custom connector. Give it a name, paste the address above and leave the client ID and secret empty. Your browser opens to sign in.

On Team and Enterprise plans, an owner adds it first under Organization settings, Connectors.

claude mcp add --transport http {{.Server}} {{.Address}}

Then run /mcp, pick {{.Server}} and sign in.

codex mcp add {{.Server}} --url {{.Address}}
codex mcp login {{.Server}}

In ~/.gemini/settings.json:

{
  "mcpServers": {
    "{{.Server}}": { "httpUrl": "{{.Address}}" }
  }
}

Then run /mcp auth {{.Server}} to sign in.

Other programs on your computer work too, if they speak MCP over HTTP and sign in with OAuth through a local address (127.0.0.1 or localhost).

Signing in

The first time your agent connects, your browser opens. You choose read and write, or read only, and sign in with GitHub. You see the vaults (repositories) your GitHub account can read, and change those you can push to. Every change is a commit authored by you.

You sign in again after 90 days, or sooner if you revoke the app in your GitHub settings.

What agents can do

  • search: find documents by keywords, across every vault you can read.
  • read, list, history: read a document, browse a vault, see what changed.
  • query: read-only SQL for what search can't answer, such as stale runbooks or what links here.
  • edit, write, move, delete: change documents, each change a commit.

Try it: ask your agent "What do we know about how deploys work? Write down what you learn."
